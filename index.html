QuixiDesk — volkdude85 edition

A Flatpak of a native Rust desktop workspace for AI. x86_64, runs in desktop mode on a Steam Deck and on any x86_64 Linux box with Flatpak.

Install

flatpak install --user --from https://volkdude85.github.io/quixidesk-volkdude85-published/io.github.volkdude85.quixidesk.flatpakref

Then launch it from your application menu, or:

flatpak run io.github.volkdude85.quixidesk

Update

flatpak update io.github.volkdude85.quixidesk

Not on Flathub. That submission was made and turned down, for reasons that hold up: the manifest packaged a prebuilt binary where their builders compile from source, and it is a downstream edition of an application someone else maintains. The first is fixed — this repository now builds the Flatpak from 564 crates inside the sandbox with no network. The second needs the Linux platform patches to go upstream, which belongs to the person who owns that tree. Both are written out, in the maintainer's own words, in FLATHUB.md. This repository is how the edition ships in the meantime: signed, installable, and built from the patch series you can read.
